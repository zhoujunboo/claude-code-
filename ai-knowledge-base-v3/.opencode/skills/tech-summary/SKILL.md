# Tech Summary 技能

## 使用场景

当需要对 `knowledge/raw/` 中已采集的技术项目进行深度分析、提炼技术亮点、识别趋势并生成结构化分析结果时，使用此技能。适用于每日技术情报分析、热门项目价值判断、后续知识整理前的分析增强等场景。

## 执行步骤

1. 读取 `knowledge/raw/` 最新采集文件
   优先定位最近一次生成的原始采集 JSON，确认其结构完整、可供分析。

2. 逐条深度分析
   对每个项目执行统一分析：生成不超过 50 字的中文摘要；提炼 2-3 个技术亮点，要求基于事实，不写空泛判断；给出 1-10 分评分并附简短理由；补充标签建议。

3. 趋势发现
   基于全部项目识别共同主题、反复出现的技术方向、值得关注的新概念或新范式，形成趋势观察。

4. 输出分析结果 JSON
   将逐条分析结果和整体趋势汇总为结构稳定的 JSON，供后续整理或入库流程直接消费。

## 注意事项

- 必须基于采集结果和可验证公开信息进行分析，不能臆造事实。
- 摘要要求中文表达自然，长度不超过 50 字。
- 技术亮点必须“用事实说话”，优先描述能力、机制、特点、适用场景，不要只写主观评价。
- 评分必须附带理由，并严格遵守统一评分标准。
- 对 15 个项目的评分分布要有克制，`9-10` 分项目不超过 2 个。
- 标签建议应便于后续沉淀为知识条目标签，建议使用英文小写。

## 评分标准

- `9-10`：改变格局，必须重点关注
- `7-8`：直接有帮助，建议优先关注
- `5-6`：值得了解，适合持续跟踪
- `1-4`：可略过，价值有限
